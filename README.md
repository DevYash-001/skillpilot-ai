# SkillPilot AI 🚀

SkillPilot AI is an AI Engineer career and skill-gap analysis platform.

## Day 1

Built the first version of the Skill Gap Calculator.

### Current Features

- AI Engineer skill database
- User skill input
- Skill comparison
- Missing skill detection
- Basic AI Engineer readiness score
- Next skill recommendation

### Technologies

- Python
- JSON

## Project Goal

SkillPilot AI will eventually analyze resumes, GitHub projects,
skills, and learning progress to generate a personalized
AI Engineer roadmap.
